# 多知识库实现方案

> **文档状态**：📦 已归档 — 多知识库架构已于 2026-03 落地（NebulaGraph + KBManager + 多库 API）。  
> 任务拆解见 [task_01](./task_01_database_design.md)～[task_07](./task_07_content_filter_multi_kb_design.md)；现行 RAG 说明见 [docs/知识库算法和架构.md](../docs/知识库算法和架构.md)。  
> **阅读注意**：下文 §1.2 等处的 **Neo4j** 为迁移前背景；**现行图库为 NebulaGraph（每 KB 独立 Space）**。跨库检索见 `multi_kb_search_tool` → `retrieve_context`。

## 一、需求背景

### 1.1 业务需求

用户需要创建多个学科知识库（如物理、化学、生物等），实现：
- 知识库独立管理（创建、删除、切换）
- 数据物理隔离，查询性能互不影响
- 支持跨知识库查询（可选）

### 1.2 迁移前架构限制（历史背景，2026-03 前）

| 组件 | 迁移前方案 | 限制 |
|-----|---------|-----|
| 图数据库 | Neo4j 社区版 | 单机架构，Label 隔离有性能影响 |
| 向量数据库 | Milvus | 已支持 namespace 隔离 ✅ |
| KV 存储 | Redis | 已支持 key 前缀隔离 ✅ |
| 业务数据库 | MySQL | 需新增知识库管理表 |

### 1.3 为什么选择 NebulaGraph

| 对比项 | Neo4j 社区版 | NebulaGraph |
|-------|-------------|-------------|
| 架构 | 单机 | 分布式（存算分离） |
| 多知识库隔离 | Label 隔离（逻辑隔离） | **Space 隔离（物理隔离）** |
| 数据规模 | < 1亿节点 | 万亿级节点/边 |
| 写入性能 | 中等 | 10万+ TPS |
| 查询性能 | 小规模快，大规模下降 | 大规模稳定 |
| 扩展性 | 不支持水平扩展 | 支持水平扩展 |
| 国产化 | 无 | 支持鲲鹏、飞腾 |
| 成本 | 企业版极贵 | 开源免费 |

### 3.2 NebulaGraph Schema 设计

每个知识库对应一个独立的 Space：

```ngql
-- 创建知识库时执行
CREATE SPACE IF NOT EXISTS physics (vid_type=FIXED_STRING(256));
CREATE SPACE IF NOT EXISTS chemistry (vid_type=FIXED_STRING(256));

-- 在每个 Space 中创建 Schema
USE physics;

-- 实体标签
CREATE TAG IF NOT EXISTS entity (
    entity_id STRING,
    entity_type STRING,
    description STRING,
    source_id STRING,
    file_path STRING,
    created_at TIMESTAMP
);

-- 关系类型
CREATE EDGE IF NOT EXISTS relation (
    relation_type STRING,
    description STRING,
    source_id STRING,
    file_path STRING,
    weight DOUBLE,
    created_at TIMESTAMP
);

-- 创建索引
CREATE TAG INDEX IF NOT EXISTS entity_id_idx ON entity(entity_id);
CREATE TAG INDEX IF NOT EXISTS entity_type_idx ON entity(entity_type);
CREATE EDGE INDEX IF NOT EXISTS relation_source_idx ON relation(source_id);
```

### 4.2 NebulaGraph 存储实现

```python
# backend/rag/storages/nebula_storage.py

"""
NebulaGraph 存储实现
实现 LightRAG 的 BaseGraphStorage 接口
"""

import os
import json
import asyncio
from dataclasses import dataclass, field
from typing import Any, Dict, List, Optional, Tuple

from lightrag.base import BaseGraphStorage
from lightrag.utils import logger

try:
    from nebula3.gclient.net import ConnectionPool
    from nebula3.Config import Config as NebulaConfig
    NEBULA_AVAILABLE = True
except ImportError:
    NEBULA_AVAILABLE = False
    logger.warning("nebula3-python not installed, NebulaGraph storage unavailable")


@dataclass
class NebulaGraphStorage(BaseGraphStorage):
    """
    NebulaGraph 存储实现
    
    每个 workspace 对应一个 NebulaGraph Space
    实现完全物理隔离的多知识库支持
    """
    
    namespace: str = field(default="base")
    workspace: str = field(default="base")
    global_config: Dict[str, Any] = field(default_factory=dict)
    
    _pool: Optional[ConnectionPool] = field(default=None, init=False)
    _session_pool: Optional[Any] = field(default=None, init=False)
    
    def __post_init__(self):
        if not NEBULA_AVAILABLE:
            raise ImportError("nebula3-python is required for NebulaGraph storage")
        
        self._host = os.getenv("NEBULA_HOST", "localhost")
        self._port = int(os.getenv("NEBULA_PORT", "9669"))
        self._user = os.getenv("NEBULA_USER", "root")
        self._password = os.getenv("NEBULA_PASSWORD", "nebula")
        self._space = self.workspace or self.namespace
        
    async def initialize(self):
        """初始化连接池和 Space"""
        config = NebulaConfig()
        config.max_connection_pool_size = int(
            os.getenv("NEBULA_MAX_CONNECTION_POOL_SIZE", "100")
        )
        
        self._pool = ConnectionPool()
        ok = self._pool.init([(self._host, self._port)], config)
        if not ok:
            raise RuntimeError(f"Failed to connect to NebulaGraph at {self._host}:{self._port}")
        
        session = self._pool.get_session(self._user, self._password)
        
        try:
            result = session.execute(f'CREATE SPACE IF NOT EXISTS `{self._space}` (vid_type=FIXED_STRING(256))')
            logger.info(f"[{self._space}] Created or verified space")
        except Exception as e:
            logger.warning(f"[{self._space}] Space creation warning: {e}")
        finally:
            session.release()
        
        await self._ensure_schema()
        logger.info(f"[{self._space}] NebulaGraph storage initialized")
    
    async def _ensure_schema(self):
        """确保 Schema 存在"""
        schema_statements = [
            f'USE `{self._space}`',
            '''
            CREATE TAG IF NOT EXISTS entity (
                entity_id STRING,
                entity_type STRING,
                description STRING,
                source_id STRING,
                file_path STRING,
                created_at TIMESTAMP
            )
            ''',
            '''
            CREATE EDGE IF NOT EXISTS relation (
                relation_type STRING,
                description STRING,
                source_id STRING,
                file_path STRING,
                weight DOUBLE,
                created_at TIMESTAMP
            )
            ''',
            'CREATE TAG INDEX IF NOT EXISTS entity_id_idx ON entity(entity_id)',
            'CREATE TAG INDEX IF NOT EXISTS entity_type_idx ON entity(entity_type)',
            'CREATE EDGE INDEX IF NOT EXISTS relation_source_idx ON relation(source_id)',
        ]
        
        session = self._pool.get_session(self._user, self._password)
        try:
            for stmt in schema_statements:
                try:
                    session.execute(stmt)
                except Exception as e:
                    if "Existed" not in str(e):
                        logger.debug(f"Schema statement warning: {e}")
        finally:
            session.release()
    
    async def finalize(self):
        """关闭连接池"""
        if self._pool:
            self._pool.close()
            self._pool = None
    
    def _get_session(self):
        """获取会话"""
        if not self._pool:
            raise RuntimeError("NebulaGraph not initialized")
        return self._pool.get_session(self._user, self._password)
    
    async def has_node(self, node_id: str) -> bool:
        """检查节点是否存在"""
        session = self._get_session()
        try:
            session.execute(f'USE `{self._space}`')
            result = session.execute(
                f'MATCH (n:entity) WHERE n.entity_id == "{node_id}" RETURN count(n) AS cnt'
            )
            if result.is_succeeded() and result.row_size() > 0:
                return result.row_values(0)[0].as_int() > 0
            return False
        finally:
            session.release()
    
    async def has_edge(self, source_node_id: str, target_node_id: str) -> bool:
        """检查边是否存在"""
        session = self._get_session()
        try:
            session.execute(f'USE `{self._space}`')
            result = session.execute(
                f'MATCH (s:entity)-[r:relation]->(t:entity) '
                f'WHERE s.entity_id == "{source_node_id}" AND t.entity_id == "{target_node_id}" '
                f'RETURN count(r) AS cnt'
            )
            if result.is_succeeded() and result.row_size() > 0:
                return result.row_values(0)[0].as_int() > 0
            return False
        finally:
            session.release()
    
    async def node_degree(self, node_id: str) -> int:
        """获取节点度数"""
        session = self._get_session()
        try:
            session.execute(f'USE `{self._space}`')
            result = session.execute(
                f'MATCH (n:entity)-[r]-() WHERE n.entity_id == "{node_id}" '
                f'RETURN count(r) AS degree'
            )
            if result.is_succeeded() and result.row_size() > 0:
                return result.row_values(0)[0].as_int()
            return 0
        finally:
            session.release()
    
    async def edge_degree(self, src_id: str, tgt_id: str) -> int:
        """获取边的度数（两端节点度数之和）"""
        src_degree = await self.node_degree(src_id)
        tgt_degree = await self.node_degree(tgt_id)
        return src_degree + tgt_degree
    
    async def get_node(self, node_id: str) -> Optional[Dict[str, str]]:
        """获取节点属性"""
        session = self._get_session()
        try:
            session.execute(f'USE `{self._space}`')
            result = session.execute(
                f'MATCH (n:entity) WHERE n.entity_id == "{node_id}" '
                f'RETURN n.entity_id, n.entity_type, n.description, n.source_id, n.file_path'
            )
            if result.is_succeeded() and result.row_size() > 0:
                row = result.row_values(0)
                return {
                    "entity_id": row[0].as_string(),
                    "entity_type": row[1].as_string(),
                    "description": row[2].as_string() if not row[2].is_empty() else "",
                    "source_id": row[3].as_string() if not row[3].is_empty() else "",
                    "file_path": row[4].as_string() if not row[4].is_empty() else "",
                }
            return None
        finally:
            session.release()
    
    async def get_edge(self, source_node_id: str, target_node_id: str) -> Optional[Dict[str, str]]:
        """获取边属性"""
        session = self._get_session()
        try:
            session.execute(f'USE `{self._space}`')
            result = session.execute(
                f'MATCH (s:entity)-[r:relation]->(t:entity) '
                f'WHERE s.entity_id == "{source_node_id}" AND t.entity_id == "{target_node_id}" '
                f'RETURN r.relation_type, r.description, r.source_id, r.weight'
            )
            if result.is_succeeded() and result.row_size() > 0:
                row = result.row_values(0)
                return {
                    "relation_type": row[0].as_string(),
                    "description": row[1].as_string() if not row[1].is_empty() else "",
                    "source_id": row[2].as_string() if not row[2].is_empty() else "",
                    "weight": str(row[3].as_double()) if not row[3].is_empty() else "1.0",
                }
            return None
        finally:
            session.release()
    
    async def get_node_edges(self, source_node_id: str) -> Optional[List[Tuple[str, str]]]:
        """获取节点的所有边"""
        session = self._get_session()
        try:
            session.execute(f'USE `{self._space}`')
            result = session.execute(
                f'MATCH (s:entity)-[r:relation]-(t:entity) '
                f'WHERE s.entity_id == "{source_node_id}" '
                f'RETURN t.entity_id'
            )
            edges = []
            if result.is_succeeded():
                for i in range(result.row_size()):
                    target_id = result.row_values(i)[0].as_string()
                    edges.append((source_node_id, target_id))
            return edges if edges else None
        finally:
            session.release()
    
    async def upsert_node(self, node_id: str, node_data: Dict[str, str]) -> None:
        """插入或更新节点"""
        session = self._get_session()
        try:
            session.execute(f'USE `{self._space}`')
            
            entity_type = node_data.get("entity_type", "unknown")
            description = node_data.get("description", "").replace('"', '\\"')
            source_id = node_data.get("source_id", "").replace('"', '\\"')
            file_path = node_data.get("file_path", "").replace('"', '\\"')
            
            nGQL = f'''
            INSERT VERTEX entity (
                entity_id, entity_type, description, source_id, file_path, created_at
            ) VALUES (
                "{node_id}": (
                    "{node_id}",
                    "{entity_type}",
                    "{description}",
                    "{source_id}",
                    "{file_path}",
                    timestamp()
                )
            )
            '''
            session.execute(nGQL)
        finally:
            session.release()
    
    async def upsert_edge(self, source_node_id: str, target_node_id: str, edge_data: Dict[str, str]) -> None:
        """插入或更新边"""
        session = self._get_session()
        try:
            session.execute(f'USE `{self._space}`')
            
            relation_type = edge_data.get("relation_type", "related").replace('"', '\\"')
            description = edge_data.get("description", "").replace('"', '\\"')
            source_id = edge_data.get("source_id", "").replace('"', '\\"')
            file_path = edge_data.get("file_path", "").replace('"', '\\"')
            weight = float(edge_data.get("weight", "1.0"))
            
            nGQL = f'''
            INSERT EDGE relation (
                relation_type, description, source_id, file_path, weight, created_at
            ) VALUES (
                "{source_node_id}"->"{target_node_id}": (
                    "{relation_type}",
                    "{description}",
                    "{source_id}",
                    "{file_path}",
                    {weight},
                    timestamp()
                )
            )
            '''
            session.execute(nGQL)
        finally:
            session.release()
    
    async def delete_node(self, node_id: str) -> None:
        """删除节点"""
        session = self._get_session()
        try:
            session.execute(f'USE `{self._space}`')
            session.execute(f'DELETE VERTEX "{node_id}" WITH EDGE')
        finally:
            session.release()
    
    async def remove_nodes(self, node_ids: List[str]) -> None:
        """批量删除节点"""
        for node_id in node_ids:
            await self.delete_node(node_id)
    
    async def remove_edges(self, edges: List[Tuple[str, str]]) -> None:
        """批量删除边"""
        session = self._get_session()
        try:
            session.execute(f'USE `{self._space}`')
            for src_id, tgt_id in edges:
                session.execute(f'DELETE EDGE relation "{src_id}"->"{tgt_id}"')
        finally:
            session.release()
    
    async def get_nodes_batch(self, node_ids: List[str]) -> Dict[str, Dict]:
        """批量获取节点"""
        result = {}
        for node_id in node_ids:
            node = await self.get_node(node_id)
            if node:
                result[node_id] = node
        return result
    
    async def node_degrees_batch(self, node_ids: List[str]) -> Dict[str, int]:
        """批量获取节点度数"""
        result = {}
        for node_id in node_ids:
            result[node_id] = await self.node_degree(node_id)
        return result
    
    async def get_edges_batch(self, pairs: List[Dict[str, str]]) -> Dict[Tuple[str, str], Dict]:
        """批量获取边"""
        result = {}
        for pair in pairs:
            src_id = pair["src"]
            tgt_id = pair["tgt"]
            edge = await self.get_edge(src_id, tgt_id)
            if edge:
                result[(src_id, tgt_id)] = edge
        return result
    
    async def get_nodes_edges_batch(self, node_ids: List[str]) -> Dict[str, List[Tuple[str, str]]]:
        """批量获取节点的边"""
        result = {}
        for node_id in node_ids:
            edges = await self.get_node_edges(node_id)
            result[node_id] = edges or []
        return result
    
    async def all_nodes(self) -> List[str]:
        """获取所有节点ID"""
        session = self._get_session()
        try:
            session.execute(f'USE `{self._space}`')
            result = session.execute('MATCH (n:entity) RETURN n.entity_id')
            nodes = []
            if result.is_succeeded():
                for i in range(result.row_size()):
                    nodes.append(result.row_values(i)[0].as_string())
            return nodes
        finally:
            session.release()
    
    async def all_edges(self) -> List[Tuple[str, str]]:
        """获取所有边"""
        session = self._get_session()
        try:
            session.execute(f'USE `{self._space}`')
            result = session.execute('MATCH (s:entity)-[r:relation]->(t:entity) RETURN s.entity_id, t.entity_id')
            edges = []
            if result.is_succeeded():
                for i in range(result.row_size()):
                    src = result.row_values(i)[0].as_string()
                    tgt = result.row_values(i)[1].as_string()
                    edges.append((src, tgt))
            return edges
        finally:
            session.release()
    
    async def drop(self) -> None:
        """删除整个 Space（谨慎使用）"""
        session = self._get_session()
        try:
            session.execute(f'DROP SPACE IF EXISTS `{self._space}`')
            logger.warning(f"[{self._space}] Space dropped")
        finally:
            session.release()
```

### 4.3 知识库管理器

```python
# backend/rag/knowledge_base_manager.py

"""
知识库管理器
负责多知识库的生命周期管理和实例缓存
"""

import asyncio
import os
from typing import Any, Dict, List, Optional

from lightrag.utils import EmbeddingFunc

from backend.config.loggers import get_logger
from backend.config.settings import settings
from backend.db.connection import get_session
from backend.db.crud.knowledge_base_crud import KnowledgeBaseCRUD
from backend.rag.raganything.config import RAGAnythingConfig
from backend.rag.raganything.raganything import RAGAnything
from backend.rag.storages.nebula_storage import NebulaGraphStorage

logger = get_logger(__name__)


class KnowledgeBaseManager:
    """
    知识库管理器
    
    功能：
    1. 管理多个知识库实例
    2. 处理知识库的创建、删除、切换
    3. 维护实例缓存，避免重复初始化
    """
    
    def __init__(self):
        self._instances: Dict[str, RAGAnything] = {}
        self._configs: Dict[str, RAGAnythingConfig] = {}
        self._default_kb: Optional[str] = None
        self._lock = asyncio.Lock()
        
        self._embedding_func: Optional[EmbeddingFunc] = None
        self._llm_model_func: Optional[Any] = None
        self._vision_model_func: Optional[Any] = None
    
    async def initialize(
        self,
        embedding_func: EmbeddingFunc,
        llm_model_func: Any,
        vision_model_func: Optional[Any] = None,
    ):
        """初始化管理器，设置共享的模型函数"""
        self._embedding_func = embedding_func
        self._llm_model_func = llm_model_func
        self._vision_model_func = vision_model_func
        
        await self._load_existing_knowledge_bases()
    
    async def _load_existing_knowledge_bases(self):
        """从数据库加载已存在的知识库"""
        session = get_session()
        try:
            crud = KnowledgeBaseCRUD(session)
            kb_list = crud.get_all_active()
            
            for kb in kb_list:
                if kb.is_default and self._default_kb is None:
                    self._default_kb = kb.kb_code
                logger.info(f"Loaded knowledge base: {kb.kb_name} ({kb.kb_code})")
        finally:
            session.close()
    
    async def create_knowledge_base(
        self,
        kb_code: str,
        kb_name: str,
        subject: Optional[str] = None,
        description: Optional[str] = None,
        owner_id: Optional[str] = None,
        set_default: bool = False,
    ) -> Dict[str, Any]:
        """
        创建新知识库
        
        Args:
            kb_code: 知识库编码（用于存储空间命名，只能包含字母、数字、下划线）
            kb_name: 知识库名称
            subject: 学科分类
            description: 描述
            owner_id: 所有者ID
            set_default: 是否设为默认知识库
            
        Returns:
            创建结果
        """
        async with self._lock:
            import re
            if not re.match(r'^[a-zA-Z][a-zA-Z0-9_]*$', kb_code):
                return {
                    "success": False,
                    "error": "kb_code must start with a letter and contain only letters, numbers, and underscores"
                }
            
            session = get_session()
            try:
                crud = KnowledgeBaseCRUD(session)
                
                existing = crud.get_by_code(kb_code)
                if existing:
                    return {"success": False, "error": f"Knowledge base with code '{kb_code}' already exists"}
                
                kb = crud.create(
                    kb_code=kb_code,
                    kb_name=kb_name,
                    subject=subject,
                    description=description,
                    owner_id=owner_id,
                    nebula_space=kb_code,
                    milvus_collection_prefix=kb_code,
                    redis_key_prefix=kb_code,
                    is_default=set_default,
                )
                
                if set_default or self._default_kb is None:
                    self._default_kb = kb_code
                
                await self._create_storage_spaces(kb_code)
                
                logger.info(f"Created knowledge base: {kb_name} ({kb_code})")
                
                return {
                    "success": True,
                    "kb_id": kb.kb_id,
                    "kb_code": kb_code,
                    "kb_name": kb_name,
                }
                
            except Exception as e:
                logger.exception(f"Failed to create knowledge base: {e}")
                return {"success": False, "error": str(e)}
            finally:
                session.close()
    
    async def _create_storage_spaces(self, kb_code: str):
        """创建存储空间"""
        if os.getenv("NEBULA_URI"):
            storage = NebulaGraphStorage(
                namespace=kb_code,
                workspace=kb_code,
                global_config={},
                embedding_func=self._embedding_func,
            )
            await storage.initialize()
            await storage.finalize()
        
        logger.info(f"Created storage spaces for: {kb_code}")
    
    async def get_or_create_instance(self, kb_code: str) -> RAGAnything:
        """
        获取或创建知识库实例
        
        如果实例已缓存，直接返回
        否则创建新实例并缓存
        """
        if kb_code in self._instances:
            return self._instances[kb_code]
        
        async with self._lock:
            if kb_code in self._instances:
                return self._instances[kb_code]
            
            session = get_session()
            try:
                crud = KnowledgeBaseCRUD(session)
                kb = crud.get_by_code(kb_code)
                
                if not kb:
                    raise ValueError(f"Knowledge base '{kb_code}' not found")
                
                if kb.status != "active":
                    raise ValueError(f"Knowledge base '{kb_code}' is not active (status: {kb.status})")
                
                config = RAGAnythingConfig(
                    working_dir=os.path.join(settings.rag_work_dir or "./rag_storage", kb_code),
                )
                self._configs[kb_code] = config
                
                lightrag_kwargs = {
                    "workspace": kb_code,
                }
                
                if os.getenv("NEBULA_URI"):
                    lightrag_kwargs["graph_storage"] = "NebulaGraphStorage"
                
                rag = RAGAnything(
                    config=config,
                    llm_model_func=self._llm_model_func,
                    vision_model_func=self._vision_model_func,
                    embedding_func=self._embedding_func,
                    lightrag_kwargs=lightrag_kwargs,
                )
                
                init_result = await rag._ensure_lightrag_initialized()
                if not init_result.get("success"):
                    raise RuntimeError(f"Failed to initialize RAG instance: {init_result.get('error')}")
                
                self._instances[kb_code] = rag
                
                logger.info(f"Initialized RAG instance for: {kb_code}")
                return rag
                
            finally:
                session.close()
    
    async def delete_knowledge_base(self, kb_code: str) -> Dict[str, Any]:
        """
        删除知识库
        
        警告：此操作会删除所有相关数据，不可恢复
        """
        async with self._lock:
            if kb_code in self._instances:
                rag = self._instances.pop(kb_code)
                await rag.finalize_storages()
            
            session = get_session()
            try:
                crud = KnowledgeBaseCRUD(session)
                kb = crud.get_by_code(kb_code)
                
                if not kb:
                    return {"success": False, "error": f"Knowledge base '{kb_code}' not found"}
                
                await self._drop_storage_spaces(kb_code)
                
                crud.delete(kb.kb_id)
                
                if self._default_kb == kb_code:
                    self._default_kb = None
                
                logger.info(f"Deleted knowledge base: {kb_code}")
                
                return {"success": True, "kb_code": kb_code}
                
            except Exception as e:
                logger.exception(f"Failed to delete knowledge base: {e}")
                return {"success": False, "error": str(e)}
            finally:
                session.close()
    
    async def _drop_storage_spaces(self, kb_code: str):
        """删除存储空间"""
        if os.getenv("NEBULA_URI"):
            storage = NebulaGraphStorage(
                namespace=kb_code,
                workspace=kb_code,
                global_config={},
                embedding_func=self._embedding_func,
            )
            await storage.initialize()
            await storage.drop()
            await storage.finalize()
        
        logger.info(f"Dropped storage spaces for: {kb_code}")
    
    def get_default_kb(self) -> Optional[str]:
        """获取默认知识库编码"""
        return self._default_kb
    
    def list_knowledge_bases(self) -> List[Dict[str, Any]]:
        """列出所有知识库"""
        session = get_session()
        try:
            crud = KnowledgeBaseCRUD(session)
            kb_list = crud.get_all_active()
            
            return [
                {
                    "kb_id": kb.kb_id,
                    "kb_code": kb.kb_code,
                    "kb_name": kb.kb_name,
                    "subject": kb.subject,
                    "description": kb.description,
                    "doc_count": kb.doc_count,
                    "entity_count": kb.entity_count,
                    "is_default": kb.is_default,
                    "created_at": kb.created_at.isoformat() if kb.created_at else None,
                }
                for kb in kb_list
            ]
        finally:
            session.close()
    
    async def finalize_all(self):
        """关闭所有实例"""
        for kb_code, rag in self._instances.items():
            try:
                await rag.finalize_storages()
                logger.info(f"Finalized RAG instance: {kb_code}")
            except Exception as e:
                logger.error(f"Error finalizing {kb_code}: {e}")
        
        self._instances.clear()


_kb_manager: Optional[KnowledgeBaseManager] = None


def get_kb_manager() -> KnowledgeBaseManager:
    """获取知识库管理器单例"""
    global _kb_manager
    if _kb_manager is None:
        _kb_manager = KnowledgeBaseManager()
    return _kb_manager
```

```python
from typing import List, Optional
from datetime import datetime

from sqlalchemy.orm import Session

from backend.db.models import KnowledgeBase


class KnowledgeBaseCRUD:
    def __init__(self, session: Session):
        self.session = session
    
    def create(
        self,
        kb_code: str,
        kb_name: str,
        subject: Optional[str] = None,
        description: Optional[str] = None,
        owner_id: Optional[str] = None,
        nebula_space: Optional[str] = None,
        milvus_collection_prefix: Optional[str] = None,
        redis_key_prefix: Optional[str] = None,
        is_default: bool = False,
    ) -> KnowledgeBase:
        """创建知识库"""
        if is_default:
            self.session.query(KnowledgeBase).filter(
                KnowledgeBase.is_default == True
            ).update({"is_default": False})
        
        kb = KnowledgeBase(
            kb_code=kb_code,
            kb_name=kb_name,
            subject=subject,
            description=description,
            owner_id=owner_id,
            nebula_space=nebula_space or kb_code,
            milvus_collection_prefix=milvus_collection_prefix or kb_code,
            redis_key_prefix=redis_key_prefix or kb_code,
            is_default=is_default,
            status="active",
        )
        
        self.session.add(kb)
        self.session.commit()
        self.session.refresh(kb)
        
        return kb
    
    def get_by_id(self, kb_id: str) -> Optional[KnowledgeBase]:
        """根据 ID 获取知识库"""
        return self.session.query(KnowledgeBase).filter(
            KnowledgeBase.kb_id == kb_id
        ).first()
    
    def get_by_code(self, kb_code: str) -> Optional[KnowledgeBase]:
        """根据编码获取知识库"""
        return self.session.query(KnowledgeBase).filter(
            KnowledgeBase.kb_code == kb_code
        ).first()
    
    def get_all_active(self) -> List[KnowledgeBase]:
        """获取所有活跃的知识库"""
        return self.session.query(KnowledgeBase).filter(
            KnowledgeBase.status == "active"
        ).order_by(KnowledgeBase.created_at.desc()).all()
    
    def update_stats(
        self,
        kb_code: str,
        doc_count: Optional[int] = None,
        entity_count: Optional[int] = None,
        relation_count: Optional[int] = None,
    ) -> Optional[KnowledgeBase]:
        """更新统计信息"""
        kb = self.get_by_code(kb_code)
        if not kb:
            return None
        
        if doc_count is not None:
            kb.doc_count = doc_count
        if entity_count is not None:
            kb.entity_count = entity_count
        if relation_count is not None:
            kb.relation_count = relation_count
        
        kb.updated_at = datetime.now()
        self.session.commit()
        self.session.refresh(kb)
        
        return kb
    
    def set_default(self, kb_code: str) -> Optional[KnowledgeBase]:
        """设置默认知识库"""
        self.session.query(KnowledgeBase).filter(
            KnowledgeBase.is_default == True
        ).update({"is_default": False})
        
        kb = self.get_by_code(kb_code)
        if kb:
            kb.is_default = True
            self.session.commit()
            self.session.refresh(kb)
        
        return kb
    
    def delete(self, kb_id: str) -> bool:
        """删除知识库"""
        kb = self.get_by_id(kb_id)
        if not kb:
            return False
        
        self.session.delete(kb)
        self.session.commit()
        
        return True
    
    def update_status(self, kb_code: str, status: str) -> Optional[KnowledgeBase]:
        """更新状态"""
        kb = self.get_by_code(kb_code)
        if kb:
            kb.status = status
            kb.updated_at = datetime.now()
            self.session.commit()
            self.session.refresh(kb)
        return kb
```

```python
logger = get_logger(__name__)


async def migrate_knowledge_base(
    neo4j_uri: str,
    neo4j_user: str,
    neo4j_password: str,
    workspace: str,
    nebula_host: str,
    nebula_port: int,
):
    """
    迁移单个知识库
    
    Args:
        neo4j_uri: Neo4j 连接 URI
        neo4j_user: Neo4j 用户名
        neo4j_password: Neo4j 密码
        workspace: 知识库 workspace（对应 Neo4j Label 和 NebulaGraph Space）
        nebula_host: NebulaGraph 主机
        nebula_port: NebulaGraph 端口
    """
    logger.info(f"Starting migration for workspace: {workspace}")
    
    neo4j_driver = GraphDatabase.driver(neo4j_uri, auth=(neo4j_user, neo4j_password))
    
    nebula_storage = NebulaGraphStorage(
        namespace=workspace,
        workspace=workspace,
        global_config={},
        embedding_func=None,
    )
    await nebula_storage.initialize()
    
    try:
        with neo4j_driver.session() as session:
            result = session.run(f'MATCH (n:`{workspace}`) RETURN count(n) AS cnt')
            node_count = result.single()["cnt"]
            logger.info(f"Found {node_count} nodes in Neo4j")
            
            result = session.run(f'MATCH ()-[r]-() WHERE head(labels(startNode(r))) = "{workspace}" RETURN count(DISTINCT r) AS cnt')
            edge_count = result.single()["cnt"]
            logger.info(f"Found {edge_count} edges in Neo4j")
        
        batch_size = 1000
        offset = 0
        
        with neo4j_driver.session() as session:
            while True:
                result = session.run(f'''
                    MATCH (n:`{workspace}`)
                    RETURN n.entity_id AS entity_id,
                           n.entity_type AS entity_type,
                           n.description AS description,
                           n.source_id AS source_id,
                           n.file_path AS file_path
                    SKIP {offset} LIMIT {batch_size}
                ''')
                
                records = list(result)
                if not records:
                    break
                
                for record in records:
                    node_data = {
                        "entity_id": record.get("entity_id", ""),
                        "entity_type": record.get("entity_type", "unknown"),
                        "description": record.get("description", ""),
                        "source_id": record.get("source_id", ""),
                        "file_path": record.get("file_path", ""),
                    }
                    
                    await nebula_storage.upsert_node(
                        node_id=record["entity_id"],
                        node_data=node_data
                    )
                
                offset += batch_size
                logger.info(f"Migrated {offset}/{node_count} nodes")
        
        offset = 0
        with neo4j_driver.session() as session:
            while True:
                result = session.run(f'''
                    MATCH (s:`{workspace}`)-[r]->(t:`{workspace}`)
                    RETURN s.entity_id AS src_id,
                           t.entity_id AS tgt_id,
                           type(r) AS relation_type,
                           r.description AS description,
                           r.source_id AS source_id,
                           r.weight AS weight
                    SKIP {offset} LIMIT {batch_size}
                ''')
                
                records = list(result)
                if not records:
                    break
                
                for record in records:
                    edge_data = {
                        "relation_type": record.get("relation_type", "related"),
                        "description": record.get("description", ""),
                        "source_id": record.get("source_id", ""),
                        "weight": str(record.get("weight", 1.0)),
                    }
                    
                    await nebula_storage.upsert_edge(
                        source_node_id=record["src_id"],
                        target_node_id=record["tgt_id"],
                        edge_data=edge_data
                    )
                
                offset += batch_size
                logger.info(f"Migrated {offset}/{edge_count} edges")
        
        logger.info(f"Migration completed for workspace: {workspace}")
        
    finally:
        neo4j_driver.close()
        await nebula_storage.finalize()


async def main():
    neo4j_uri = os.getenv("NEO4J_URI", "bolt://localhost:7687")
    neo4j_user = os.getenv("NEO4J_USERNAME", "neo4j")
    neo4j_password = os.getenv("NEO4J_PASSWORD", "password")
    
    nebula_host = os.getenv("NEBULA_HOST", "localhost")
    nebula_port = int(os.getenv("NEBULA_PORT", "9669"))
    
    workspaces = ["physics", "chemistry", "biology"]
    
    for workspace in workspaces:
        await migrate_knowledge_base(
            neo4j_uri=neo4j_uri,
            neo4j_user=neo4j_user,
            neo4j_password=neo4j_password,
            workspace=workspace,
            nebula_host=nebula_host,
            nebula_port=nebula_port,
        )


if __name__ == "__main__":
    asyncio.run(main())
```
