# 地下水项目数据上传与处理标准

## 1. 适用范围

本标准用于地下水项目的资料上传、解析、标准化、质量检查、项目 Skill 生成和后续分析。六塘项目现有数据作为首个兼容样本。

## 2. 上传方式

推荐上传一个 ZIP 项目包：

```text
project-package.zip
  project.yaml
  README.md
  tables/
    points.xlsx
    constructed_wells.xlsx
    planned_wells.xlsx
    well_components.xlsx
    geology_layers.xlsx
    water_samples.xlsx
    water_quality.xlsx
  documents/
  images/
    image_manifest.xlsx
```

也允许在项目页面分批上传，但每批必须选择明确的 `file_role`。

## 3. 必须遵守的规则

1. 结构化表格使用 `.xlsx` 或 UTF-8 `.csv`，不推荐 `.xls`。
2. 第一行使用单层字段名，不使用合并单元格表达业务关系。
3. 一行只表示一个实体、组件、地层或检测结果。
4. 点位统一使用 `point_code`，水样统一使用 `sample_id`。
5. 编号按文本保存，避免 Excel 删除前导零。
6. 数值单元格不附带单位，单位写入字段名或独立 `unit` 列。
7. 异常不能只用颜色表示，必须填写 `quality_flag` 和 `quality_note`。
8. 坐标必须说明 CRS、EPSG/投影带号、X/Y轴含义和高程基准。
9. 原始文件只读保存，标准化数据必须保留来源文件、行列位置和原始值。

## 4. 核心数据表

### 4.1 points

统一管理已建井、计划井、地勘孔和监测点。

必填字段：

- `point_code`
- `point_type`
- `coordinate_system`
- 投影坐标或经纬度至少一组

`point_type`：

- `constructed_well`
- `planned_well`
- `geotechnical_borehole`
- `monitoring_point`

### 4.2 constructed_wells

一行一口已建井，使用 `point_code` 关联 points。长管、短管和多段筛管写入 `well_components`，不能拆成多口井。

### 4.3 geology_layers

一行一个地层，至少包含：

- `point_code`
- `layer_no`
- `top_depth_m`
- `bottom_depth_m`
- `lithology` 或 `description`

### 4.4 water_samples

一行一个水样，至少包含：

- `sample_id`
- `point_code`
- `sample_layer`

层位使用 `upper/middle/lower/unknown`。

### 4.5 water_quality

一行一个样品的一项检测结果，禁止使用“指标为行、点位为列”的宽表作为推荐格式。

必须包含：

- `sample_id`
- `parameter_code`
- `parameter_name`
- `raw_value`
- `value_status`
- `unit`

值状态：

- `detected`：检出数值。
- `not_detected`：源值为 ND，不等于 0。
- `not_tested`：源值为 `/`。
- `missing`：空白。
- `invalid`：无法解析。

## 5. 处理流程

1. 上传原始文件并计算文件哈希。
2. 识别 `file_role` 和数据版本。
3. 解析预览并生成字段映射。
4. 检查主键、类型、单位、坐标、区间和跨表关联。
5. 返回 `error/warning/info`，由用户确认提交。
6. 生成标准化 CSV/JSON、质量报告和汇总 Excel。
7. 更新 `manifest.json`、项目 `SKILL.md` 和 `data_version`。
8. 分析工具只能读取已提交版本。

## 6. 校验分级

- `error`：禁止提交，例如主键冲突、检测结果无法关联水样。
- `warning`：允许提交但限制分析，例如坐标系未确认、疑似错误、层位缺失。
- `info`：一般提示，例如存在未分类附件。

## 7. 六塘项目特殊处理

- 合并的长管/短管行拆为 `well_components`。
- 红色字体转换为 `quality_flag=suspected_error`。
- 地勘长文本解析为地层记录，同时保留原文。
- 上中下层水质宽表转换为检测长表。
- `ND`、`/`、空白和科学计数法分别处理。
- 计划井和已建井保留为不同点位类型，不自动互相覆盖。
- 两组 CGCS2000 坐标参数未确认前，禁止跨组距离和插值。
