## 一、背景与目标

### 1.1 现有问题

当前 `NuclearElectronicsAgent` 使用 LLM（Qwen3-max）进行关键词提取，存在以下问题：

| 问题 | 影响 |
|------|------|
| **延迟高** | 平均耗时 5.6 秒，严重影响用户体验 |
| **幻觉问题** | LLM 可能生成知识库中不存在的关键词，导致检索落空 |
| **成本高** | 每次查询都需要调用 LLM API |
| **不可控** | 关键词质量依赖 LLM 能力，难以优化 |

### 1.2 优化目标

- **延迟**：从 5.6 秒降至 **50-200 毫秒**
- **准确率**：关键词 100% 存在于知识库中
- **成本**：消除 LLM API 调用成本
- **可控性**：可针对领域特点优化检索策略

### 3.1 核心思路

### 3.2 三阶段检索流水线

#### 阶段一：向量检索（语义匹配）

**目的**：提取高级语义关键词

**实现**：
1. 将用户 Query 向量化
2. 在实体向量索引中检索 Top-K 相似实体
3. 返回相似度分数

**优势**：
- 语义泛化能力强（如"X光管"能匹配"X射线管"）
- 支持中英文混合检索
- 速度快（毫秒级）

#### 阶段二：BM25 检索（精确匹配）

**目的**：补充精确匹配的关键词

**实现**：
1. 对实体名称进行分词
2. 使用 BM25 算法计算相关性
3. 返回匹配分数

**优势**：
- 精确匹配能力强
- 对专业术语效果好
- 与向量检索互补

#### 阶段三：正则提取（技术参数）

**目的**：提取具体技术参数作为低级关键词

**实现**：
```python
# 核电子学技术参数正则模式
PARAM_PATTERNS = [
    # 带单位的数值参数
    r'\b\d+(?:\.\d+)?\s*(?:kV|keV|MeV|GeV|ns|μs|ms|Hz|kHz|MHz|GHz|mA|A|V|W|C|K|F|H|Ω)\b',
    
    # 专业缩写
    r'\b(?:NaI|CsI|HPGe|SiPM|PMT|ADC|DAC|FPGA|ASIC|DSP|PXI|VME|NIM|CAMAC)\b',
    
    # 中文参数名
    r'\b(?:增益|带宽|分辨率|信噪比|计数率|死时间|成形时间|上升沿|下降沿|阈值|高压|偏压)\b'
]
```

**优势**：
- 100% 准确率
- 无需外部依赖
- 速度极快（微秒级）

### 3.3 RRF 融合策略

**倒数排序融合（Reciprocal Rank Fusion）**：

```
RRF_score(entity) = Σ 1/(k + rank_i)
```

其中：
- `k` 是常数（通常为 60）
- `rank_i` 是实体在第 i 个检索结果中的排名

**优势**：
- 无需分数归一化
- 自然平衡不同检索方式的贡献
- 对异常值鲁棒

## 五、代码实现方案

### 5.1 混合关键词提取器

**文件位置**：`backend/agents/keyword_extractor.py`

**核心类设计**：

```python
@dataclass
class KeywordExtractionResult:
    high_level_keywords: list[str] = field(default_factory=list)
    low_level_keywords: list[str] = field(default_factory=list)
    entity_scores: dict[str, float] = field(default_factory=dict)


class HybridKeywordExtractor:
    """
    混合关键词提取器
    
    核心特性：
    1. 实体空间向量检索（主路径）- 提取高级语义关键词
    2. BM25 检索（辅助路径）- 补充精确匹配关键词
    3. 正则表达式（专用路径）- 提取技术参数
    4. RRF 融合策略 - 平衡不同检索方式的贡献
    """
    
    def __init__(
        self,
        milvus_uri: str,
        milvus_user: str,
        milvus_password: str,
        redis_host: str,
        redis_port: int,
        redis_password: str,
        embedding_func: Callable,
        embedding_dim: int = 4096,
    ):
        self._milvus_uri = milvus_uri
        self._milvus_user = milvus_user
        self._milvus_password = milvus_password
        self._redis_host = redis_host
        self._redis_port = redis_port
        self._redis_password = redis_password
        self._embedding_func = embedding_func
        self._embedding_dim = embedding_dim
        
        self._entity_names: list[str] = []
        self._entity_metadata: list[dict] = []
        self._faiss_index = None
        self._bm25_index = None
        self._is_initialized = False
        self._init_lock = asyncio.Lock()
    
    async def initialize(self) -> None:
        """初始化索引"""
        async with self._init_lock:
            if self._is_initialized:
                return
            
            # 1. 从 Milvus 加载实体
            await self._load_entities_from_milvus()
            
            # 2. 构建 FAISS 索引
            await self._build_faiss_index()
            
            # 3. 构建 BM25 索引
            self._build_bm25_index()
            
            self._is_initialized = True
    
    async def extract(self, query: str) -> KeywordExtractionResult:
        """提取关键词"""
        await self.initialize()
        
        result = KeywordExtractionResult()
        
        # 1. 检测查询类型
        query_type = self._detect_query_type(query)
        
        # 2. 正则提取技术参数
        result.low_level_keywords = self._extract_parameters(query)
        
        # 3. 向量检索
        vector_results = await self._vector_search(query, top_k=15)
        
        # 4. BM25 检索
        keyword_results = self._bm25_search(query, top_k=15)
        
        # 5. RRF 融合
        fused_results = self._rrf_fusion(vector_results, keyword_results, top_n=7)
        
        # 6. 填充高级关键词
        for name, score in fused_results:
            if score > 0.01:
                result.high_level_keywords.append(name)
                result.entity_scores[name] = score
        
        return result
```

### 5.2 索引构建器

**文件位置**：`backend/agents/keyword_index_builder.py`

**核心功能**：

```python
class KeywordIndexBuilder:
    """
    关键词索引构建器
    
    职责：
    1. 从 Neo4j 读取所有实体
    2. 批量生成实体向量
    3. 构建 Milvus 向量索引
    4. 构建 BM25 文本索引
    5. 缓存到 Redis
    """
    
    async def build_full_index(self) -> dict:
        """全量构建索引"""
        # 1. 从 Neo4j 读取所有实体
        entities = await self._fetch_all_entities_from_neo4j()
        
        # 2. 批量生成向量
        embeddings = await self._batch_embed_entities(entities)
        
        # 3. 创建/更新 Milvus Collection
        await self._upsert_to_milvus(entities, embeddings)
        
        # 4. 构建 BM25 索引
        bm25_index = self._build_bm25_index(entities)
        
        # 5. 缓存到 Redis
        await self._cache_to_redis(entities, bm25_index)
        
        return {
            "entity_count": len(entities),
            "status": "success"
        }
    
    async def incremental_update(
        self,
        added_entities: list[dict],
        deleted_entities: list[str]
    ) -> dict:
        """增量更新索引"""
        # 1. 删除已移除的实体
        if deleted_entities:
            await self._delete_from_milvus(deleted_entities)
        
        # 2. 添加新实体
        if added_entities:
            embeddings = await self._batch_embed_entities(added_entities)
            await self._upsert_to_milvus(added_entities, embeddings)
        
        # 3. 重建 BM25 索引
        await self._rebuild_bm25_index()
        
        return {
            "added": len(added_entities),
            "deleted": len(deleted_entities),
            "status": "success"
        }
```

### 9.2 BM25 分词配置

```python
def tokenize_for_bm25(text: str) -> list[str]:
    """核电子学领域专用分词"""
    import jieba
    
    # 加载核电子学词典
    jieba.load_userdict("backend/data/nuclear_electronics_dict.txt")
    
    words = jieba.lcut(text)
    
    # 过滤停用词和短词
    return [w for w in words if len(w) >= 2 and not w.isspace()]
```
