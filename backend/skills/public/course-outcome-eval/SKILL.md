# 课程达成度评价（course-outcome-eval）

面向《材料力学》等课程的试卷分析与教学目标达成度评价。

## 评价实施办法要点
- 两种达成度方法：方法二（course_average）= 平时表现达成度×0.4 + 目标考试题得分率×0.6；
  方法一（quantitative）= 学生各环节加权得分/加权满分。
- 平时表现达成度 = 平时成绩均值 / 100（grade_sheet_avg 口径）。
- 三套成绩分段口径互不相同（试卷分析表 6 段 / 成绩单 5 段 / 附表 2 五档），不得混用。

## 禁止行为
- 不得编造或推算任何分数、人数、得分率、达成度数值——只能引用工具返回值。
- 不得复述往年报告的措辞。
- 引用题目必须用「第X题」并确保题号在数据模型中存在。
- 不得对未确认映射的目标给出达成度结论。

## 报告结构
- 试卷分析表：基本情况 / 题型及分值分布 / 成绩分布表 / 得分率分析 / 定性结论。
- 附表 1：课程目标与毕业要求对应关系 + 达成度分析结果评价。
- 附表 2：课程总评成绩分析 + 达成度情况 + 平时表现达成度 + 样本达成度分布。
- 附表 3：学生个体明细 + 实际达成度平均值。
